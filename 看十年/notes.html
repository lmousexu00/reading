看十年（上下）读书笔记

曾鸣书院公开课 · AI 时代的商业和经济 / AI 原生组织和智能战略

一句话总结

AI 真正改变的不是某个工具或岗位，而是价值创造、组织协作与战略形成的底层机制：企业必须围绕真实任务建立“行动—反馈—学习”的闭环，让机器智能、个人认知与组织能力共同形成复利。

核心判断

这场公开课不是在给出一张确定的未来地图，而是在提供一套观察未来的方法。所谓“看十年”，不是猜十年后会出现什么产品，而是把我们行动背后的隐含假设说清楚；“想三年”，是判断即将发生的结构性变化；“干一年”，则是用行动获取真实反馈。

整场分享可以压缩成四个递进的判断：

  1. 商业会从销售标准产品，转向理解意图并交付结果。 AI 扩大优质供给，让个性化服务从昂贵的例外变成可规模化的常态。
  2. AI 原生应用的关键不是“用了 AI”，而是重构价值。 产品、工作流、组织和商业模式都要从可规模化调用的机器智能重新出发。
  3. AI 时代的价值引擎是智能复利。 系统做真实工作、获得结果反馈、变得更聪明，再承接更高价值的工作，领先差距由此持续扩大。
  4. 组织与战略也必须成为学习系统。 岗位让位于任务，管理让位于能力编排，静态规划让位于愿景驱动的战略发现。

1. “看十年”是一种战略学习框架

“看十年、想三年、干一年”的价值，不是让人显得有远见，而是建立三个时间尺度之间的张力。

  • 看十年：识别长期驱动力、底层规律与不变量，避免被短期噪音牵着走。
  • 想三年：判断竞争格局、技术临界点、客户价值和关键能力会发生怎样的结构性变化。这是最难也最重要的一层。
  • 干一年：把假设变成行动，用市场和用户反馈校验判断。

因此，战略不是一份写完后等待执行的计划，而是一组持续更新的 working hypothesis：

假设 → 行动 → 真实反馈 → 新洞察 → 修正假设

这套框架的重要提醒是：长期主义不等于坚持原来的答案，而是长期坚持学习同一个重要问题。

2. 商业范式：从“千人一面”到“一人千面”

曾鸣用三次商业范式变化描述 AI 的位置：

时代 主要矛盾 核心机制 典型形态
工业时代 供给不足 标准化、流水线、科层制 千人一面
互联网时代 生产过剩与信息不对称 搜索、推荐、规模化匹配 千人千面
AI 时代 优质供给稀缺、个体意图未被满足 理解意图、动态生成、结果交付 一人千面

当下大量 AI 应用仍停留在替代重复劳动、降低成本。这当然有价值，但天花板有限。更大的机会，是让过去昂贵、稀缺、无法普及的优质服务成为大众供给，例如私人医生、老师、理财顾问、旅行顾问和个人助理。

推荐系统仍是在根据相似人的历史行为“猜”你可能需要什么；AI 的理想形态则是持续理解一个人在不同情境中的真实意图，并动态组织供给。这意味着商业起点会从“我有什么产品可以卖”，转为“用户此刻真正想完成什么”。

未来的核心入口，也不再只是流量入口，而是用户愿意首先表达真实意图的入口。谁更可信、更了解用户、更能对结果负责，谁就可能拥有新的商业主导权。

3. AI 原生：不是加一个助手，而是重新设计系统

AI 原生并不由公司的成立年代决定，也不等于在旧流程里加入 Copilot。它要求企业以可规模化调用的机器智能为新生产要素，反向重构产品、工作流、组织和商业模式。

判断一个产品是否足够“原生”，可以检查四件事：

  1. 是否创造了过去无法实现的用户体验或客户价值；
  2. 是否依赖真正的原生技术突破，而不是简单包装模型能力；
  3. 是否倒逼基础设施创新，从而低成本服务海量用户；
  4. 是否形成了与新价值相匹配的商业模式。

从历史看，通用技术通常经历三个阶段：基础设施成熟，原生产品爆发，最终渗透全社会。电力、汽车和互联网都不是在技术诞生时立刻改变世界，而是在可靠性、成本和使用门槛越过临界点之后，应用才密集涌现。

曾鸣把当前 AI 类比为互联网的 1993 年：基础能力已经出现，但真正降低普通用户与开发者门槛的“浏览器式突破”仍在形成。未来三五年的核心，可能是 Agent 大爆发，然后逐渐出现能调度多种 Agent 的 AgentOS 或超级个人助理。

这个类比很有启发性，但不能机械套用。AI 比早期 Web 更资本密集，也更受能源、监管、隐私、责任和模型可靠性约束。因此，“应用即将爆发”应被当作需要持续验证的工作假设，而不是确定的时间表。

4. Agent 的终点：从对话、行动到负责

可以把 Agent 的能力分成三层：

  1. 对话：理解问题并生成回应；
  2. 行动：调用工具、拆解任务、完成长程工作；
  3. 负责：稳定交付结果，说明过程，在错误中学习，并在能力边界处主动求助。

真正的商业价值集中在第三层。只有 AI 能端到端接管任务并对可验证结果负责，它才能获得完整反馈，进入持续学习。若系统总是在关键处把任务退还给人，最有价值的经验就留在闭环之外。

但“负责”也带来尚未解决的问题：医疗、金融或法律 Agent 造成损失时，模型商、应用商、工具提供方和用户如何分担责任？AI 能否可靠判断何时应该求助？过程可验证性、权限边界和人工兜底因此不是配套功能，而是产品本体。

5. 智能复利：AI 时代的价值创造引擎

工业时代的典型引擎是规模经济，互联网时代是网络效应，AI 时代则可能是智能复利：

完成更多真实工作 → 获得更多结果反馈 → 学得更聪明 → 承接更复杂、更高价值的工作 → 获得更高质量的反馈

系统首先要跨过“60 分上岗线”，才能独立完成端到端任务。为此，企业需要设计 Agent、建立上下文与知识体系、蒸馏专家经验、搭建实验环境，并与首批客户共同训练。

一旦闭环启动，复杂任务会流向更强的 AI，更强的 AI 又得到更多数据、人才和高价值任务。这就是“黑洞效应”或“智者恒强”。作者将竞争规律概括为“高维吞噬低维”，并认为 AI 创业的首要指标不是短期盈利，而是智能进化速度。

这个判断需要加一个边界：进化速度不能脱离现金流、数据权、客户信任和反馈质量。许多真实任务反馈缓慢、目标模糊，甚至无法自动验证；并非所有行业都能自然形成快速复利。垂直知识、监管、本地化和客户关系，也可能阻止市场简单地被一个“智能黑洞”吞并。

6. 人的价值：从知识工作者到创智人才

当知识获取和执行成本显著下降，人的稀缺性会转移到方向选择、问题定义、原创判断和协同落地。曾鸣把这种角色称为“创智人才”。

创智人才的关键特征包括：

  • 高能动性：主动认领问题并对结果负责；
  • 强烈好奇心与快速学习能力；
  • 从第一性原理重新定义问题；
  • 能跨越专业边界，形成新的认知；
  • 能编排人类与机器智能，把洞察变成结果；
  • 能在高压和不确定性中保持情绪稳定。

AI 会放大一个人的能力，也会放大其情绪噪音与人格缺陷。因此，小团队不能只追逐“技术明星”；自我觉察、建设性冲突、协作意愿和从失败中学习，同样是高杠杆能力。

7. AI 原生组织：从岗位制到任务网络

工业时代组织的基本单元是岗位，围绕岗位建立部门、汇报线、流程和绩效体系。AI 原生组织的基本单元则更可能是任务。

面对一项工作，新的组织设计顺序是：

  1. 要完成的真实任务是什么？
  2. 任务需要怎样的能力组合？
  3. 哪些能力可由 Agent 独立完成？
  4. 现有人才可补齐哪些缺口？
  5. 最后才判断是否需要招聘。

组织因此从固定科层转向“任务驱动的能力协同网络”。人不再只按岗位被分配工作，而可以围绕问题主动认领责任；Agent 也不只是被人调用，而会在遇到能力边界时主动调用人类专家。

管理者的角色随之改变：从招聘、分工、上传下达和信息汇总，转向设计能力结构、动态匹配任务、编排人机协作、发展人才，并为最终结果兜底。传统中层的信息中转功能会缩减，但跨项目协调、人才成长、风险判断和责任承担不会消失。

8. 组织 OS：让整个组织变聪明

每个人都使用 AI，并不等于组织获得了智能。局部效率甚至可能制造更多信息和协调成本。真正重要的问题是：整个组织是否在持续变聪明？

组织 OS 是一种制度与技术共同构成的底座，它让组织具备完整的学习闭环：

观察与感知 → 分析 → 建议 → 行动 → 反馈 → 学习 → 再行动

它至少需要四层能力：

  • 组织记忆：记录事实、判断、分歧、证据来源与历史决策，而不仅保存最终结论；
  • 上下文调用：让人和 AI 在正确的任务与时点获得相关背景；
  • 能力编排：把人、Agent、数据和既有 SaaS 组合进端到端工作流；
  • 反馈沉淀：把一线经验、失败教训和优秀实践转化为可复用能力。

“Context not Control”在这里尤其重要。共享的不应只是两页结论，还应包括完整思考过程、AI 对话、隐含假设和证据链。充分上下文可以减少命令与审批，让成员自主判断，也使协作从信息同步走向认知共创。

但透明并非越多越好。全面记录可能演变为监控文化，错误信息也可能在组织记忆里长期固化。谁能写入、修改、调用和遗忘，如何保护个人隐私、商业秘密与心理安全，必须成为组织 OS 的治理层。

9. 战略创新：从静态规划到愿景驱动的战略发现

高度不确定的环境中，传统的“五年规划—年度拆解—KPI 执行”会迅速过时。替代方案是 Vision-driven Strategy Discovery：

愿景 → 三年战略框架 → 当下行动组合 → 真实反馈 → 解释与洞察 → 校验愿景并修正战略

愿景不是不可动摇的口号，而是方向、价值基准和一项可以修正的假设。三年框架定义路径、里程碑、关键能力和客户价值突破；一年行动除了创造业绩，还承担获取反馈的任务。

作者进一步把战略生成系统类比为机器学习：

机器学习要素 组织战略中的对应物
算法 共同的战略方法论与思考语言
算力 高质量人才及其“大脑联网”
数据 充分、实时、完整、闭环的真实反馈
模型输出 战略洞察与资源配置决策
持续训练 实验、复盘、共创与认知更新

因此，未来的战略竞争不只是“谁的战略更好”，而是“谁的战略生成系统更强”：谁能更快看到事实、更诚实暴露分歧、更深入形成洞察，并把洞察转化为下一轮行动。

AI 越擅长处理信息，高质量的线下互动反而越重要。人的面对面交流应从汇报和文档同步中解放出来，用于处理隐含假设、价值冲突、认知模型与真正的共创。

一张行动清单

对个人

  • 把学习设计成闭环：提问、行动、反馈、复盘、更新模型。
  • 少问“我掌握什么知识”，多问“我能定义并解决什么复杂问题”。
  • 用 AI 扩展跨领域理解，把自己的时间留给选择、判断和创造。
  • 主动认领真实问题，并建立可验证的结果标准。

对创业者

  • 先定义一个 AI 可端到端负责、结果可验证的真实任务，而不是先做零散提效工具。
  • 明确“60 分上岗线”：成功指标、失败边界、反馈信号和人工兜底。
  • 与愿意共创的首批客户建立高质量反馈闭环。
  • 同时追踪任务成功率、人工介入率、错误复发率和经验复用率。
  • 选择优质供给长期稀缺、并能随学习不断扩展价值边界的场景。

对管理者

  • 把招聘申请改写成“任务—能力—自动化程度—人才缺口”分析。
  • 先建设组织记忆，保存结论背后的证据、分歧与上下文。
  • 每项战略实验明确：验证什么假设、收集什么信号、何时复盘、如何影响下一步。
  • 衡量组织是否变聪明，而不只统计个人节省了多少时间。
  • 会前由 AI 汇总上下文，会中处理分歧与隐含假设，会后沉淀共识与证据链。

我的批注：最值得带走的三件事

1. 不要把 AI 项目做成“工具部署”，要把它做成“学习系统”

最常见的误区，是用使用人数、调用次数或节省工时衡量 AI 转型。这些指标只说明工具被使用，不能说明企业形成了新能力。更有效的问题是：AI 是否端到端承担了真实任务？结果是否可验证？经验是否进入下一轮工作？

2. 组织记忆可能是组织 OS 的最低可行起点

与其一开始就建设宏大的智能体平台，不如先让关键决策、证据、分歧和反馈可检索、可追溯、可调用。没有上下文，Agent 只能做通用回答；没有反馈，组织也无法产生复利。

3. “高能动性”必须与责任和边界同时设计

任务制、主动认领和充分授权可以释放创造力，也可能带来责任碎片化、持续竞标压力和心理不安全。真正成熟的 AI 原生组织，既要鼓励探索，也要清楚定义最终责任、风险边界与失败后的学习机制。

开放问题

  • 用户真的愿意把最真实的意图交给同一个 AI 吗？信任、隐私和可迁移性将如何影响入口竞争？
  • 当 Agent 造成现实损失时，责任链怎样设计才既可追责又不压制创新？
  • 哪些行业拥有足够快、足够真实的反馈，最先形成智能复利？
  • 组织记忆由谁维护，错误判断如何更正，哪些信息应当被遗忘？
  • 如何衡量“组织变聪明”：决策速度、预测准确度、反馈周期，还是客户价值？
  • 任务网络如何避免短期主义、隐形劳动和责任模糊？
  • 什么样的长期愿景既足够稳定，又允许在新事实面前被修正？

阅读结论

这场分享最有价值的地方，不是对 2027 或 2028 年的具体预测，而是把 AI 时代的商业、组织与战略统一在“学习闭环”之下。智能商业解决如何更深地理解并满足个体意图；智能复利解释价值怎样积累；组织 OS 让个体经验成为集体能力；战略发现则保证组织不断用真实世界修正自己。

如果只能记住一句话，可以记住：AI 不只是一个更聪明的工具，而是一种把学习嵌入价值创造全过程的新生产方式。
